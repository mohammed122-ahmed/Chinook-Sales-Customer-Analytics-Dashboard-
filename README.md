# Chinook-Sales-Customer-Analytics-Dashboard-

•Extracted and integrated data from the Chinook relational database into Power BI using SQL.
•Performed data cleaning, transformation, and ETL using Power Query.
•Built a relational data model and optimized table relationships for analysis.
•Developed DAX measures and KPIs to analyze sales, revenue, customers, artists, albums, and genres.
•Created interactive dashboards with slicers, filters, and drill-through functionality.
•Analyzed customer, employee, genre, and country-level performance to generate actionable business insights.
Technologies: SQL, MySQL, Power BI, DAX, Power Query, Data Modeling, ETL, Data Analysis
